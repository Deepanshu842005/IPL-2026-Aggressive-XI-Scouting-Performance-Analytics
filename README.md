IPL 2026: Aggressive XI Scouting & Performance Analytics


Project Overview

This end-to-end pipeline scouts an "Aggressive XI" for IPL 2026 using Python, SQL, and Power BI. By analyzing 17 years of ball-by-ball data (2008-2024), it moves beyond basic averages to prioritize Situational Impact (Match Phases) and Venue Adaptability. The project features custom DAX metrics and interactive matrices for data-driven player recruitment and auction strategy.  

The Technical Pipeline
EDA & Pre-processing (Python): Cleaned raw datasets and engineered features like Dot Ball % and Phase-wise Strike Rates using Pandas.

Database Management (PostgreSQL): Hosted the delivery-level data in a relational database for complex SQL aggregations.

Visualization (Power BI): Developed an interactive dashboard using DAX, Bookmarks, and Selection Panes for seamless scouting.

Repository Structure
📂 Source_Code/: Contains the Jupyter Notebook (.ipynb) and SQL scripts (.sql).

📂 Dashboard/: The Power BI Desktop file (.pbix) for the interactive visuals.

📂 Data/: Processed dataset (Zip format to handle file size limits).

📄 IPL_2026_Project_Report.pdf: Detailed technical documentation and methodology.

📄 Scouting_Presentation.pdf: High-level project summary and business recommendations.

Key Analytical Features
Aggression Matrix: Identifies elite batsmen based on Strike Rate vs. Average Runs.

Lethality Matrix: Evaluates bowlers by comparing Economy Rate and Strike Rate.

Venue Insights: Performance breakdowns across iconic grounds like Chepauk and Wankhede.
