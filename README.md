# IPL-2026-Aggressive-XI-Scouting-Performance-Analytics
This end-to-end pipeline scouts an "Aggressive XI" for IPL 2026 using Python, SQL, and Power BI. By analyzing 17 years of ball-by-ball data, it moves beyond basic averages to prioritize Situational Impact and Venue Adaptability. The project features custom DAX metrics and interactive matrices for data-driven player recruitment and auction strategy.
